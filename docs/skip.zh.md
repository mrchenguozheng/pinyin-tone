# `skip`

`M2`、`A4`、`O2` 会和拼音撞车——`m`、`a`、`o` 本身就是音节，所以 `M2` 会变成 `Ḿ`。`skip` 让你在选项里一次说清哪些片段要保持原样。

English: [skip.md](skip.md)

```javascript
markTones('M2 货币供应量 hao3', {skip: 'M2'});   // 'M2 货币供应量 hǎo'
markTones('M2 A4 N3', {skip: ['M2', 'A4']});     // 'M2 A4 Ň'
```

## 规则

字符串或数组，比的都是**整个片段**，并且区分大小写：`'M2'` 碰不到 `M20`（那是另一个片段），也碰不到 `m2`（另一个字符串）。规则就这一条——没有模式、没有谓词，文本里也不含任何标记字符。

## 规则以片段为单位

一条规则覆盖该片段的每一次出现：文本 `M2 M2` 得到 `M2 M2`，不会是「保一个转一个」。如果一次调用里需要两种结果，把文本切开，分别调用。

```javascript
markTones('M2 M2', {skip: 'M2'});  // 'M2 M2'
```

只有本来会被转换的片段才会去询问规则——这是一条纯性能捷径，不是第二条语义。

## 文本里没有标记字符

因为文本不携带任何标记，普通内容可以原样通过：

```javascript
markTones('C:\\Users');        // 原样    一个路径
markTones('\\texttt{nǐ}');     // 原样    一条 LaTeX 命令
markTones('\\ni3');            // '\\nǐ'  反斜杠只是普通字符
```

最后一条值得单独说清楚：反斜杠不保护任何东西。看起来像音节的片段，无论在前面加什么，照样会被标调。如果需要它保持原样，就把它写进 `skip`——那是「别动它」唯一的通道，输入因此保持不含指令。

## 为什么不接受 `RegExp`

正则被刻意排除在外：正则读起来是「在文本里搜索」，而这里的规则只看得到一个片段。像 `(?<=今天 )` 这样的后行断言永远不可能命中，`^`/`$` 也会锚在片段两端而不是文本两端。两种情况都会静默失败，那还不如根本不支持。

函数谓词同样不接受——它把一个声明式选项变成命令式代码，而且同样受片段级粒度的限制。传 `RegExp`、函数、`true`、`{}` 或空数组，都等同于没传这个选项；数组里的非字符串项会被丢掉。

## 刻意不做的两个写法

`onSkip` 回调和成对的 `{{ }}` 标记是刻意不提供的。它们会在 `skip` 列表已经能覆盖的场景里，再引入一个回调概念和一层解析——调用方手上就有文本，可以自己算出这个列表，例如 `[...text.matchAll(/[A-Z]{1,2}[1-5]/g)].map((m) => m[0])`。
