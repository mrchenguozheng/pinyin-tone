# `skip`

`M2`、`A4`、`O2` 会和拼音撞上——`m`、`a`、`o` 本身就是音节，所以 `M2` 会变成 `Ḿ`。`skip` 让你在选项里一次说明哪些片段要保持原样。

English: [skip.md](skip.md)

```javascript
markTones('M2 货币供应量 hao3', {skip: 'M2'});   // 'M2 货币供应量 hǎo'
markTones('M2 A4 N3', {skip: ['M2', 'A4']});     // 'M2 A4 Ň'
```

## 规则

参数可以是字符串或数组，比较的都是**整个片段**，并且区分大小写：`'M2'` 碰不到 `M20`（那是另一个片段），也碰不到 `m2`（那是另一个字符串）。规则只有这一条：没有模式匹配，没有回调谓词，文本里也不需要任何标记字符。

## 规则的作用单位是片段

一条规则对该片段的每一次出现都生效：文本 `M2 M2` 得到 `M2 M2`，不会「保留一个、转换另一个」。如果一次调用里需要两种结果，把文本切开，分别调用。

```javascript
markTones('M2 M2', {skip: 'M2'});  // 'M2 M2'
```

只有本来就会被转换的片段才会去查规则——这只是为了省时间，不构成第二条规则。

## 文本里没有标记字符

因为文本里不携带任何标记，普通内容可以原样通过：

```javascript
markTones('C:\\Users');        // 原样    一个路径
markTones('\\texttt{nǐ}');     // 原样    一条 LaTeX 命令
markTones('\\ni3');            // '\\nǐ'  反斜杠只是普通字符
```

最后一条值得单独说明：反斜杠不起保护作用。只要看起来像音节，前面加什么都会照常标调。要让它保持原样，就把它写进 `skip`——这是「别动它」唯一的途径，输入因此保持不含指令。

## 为什么不接受 `RegExp`

正则被刻意排除在外：正则表达的是「在文本里搜索」，而这里的规则只看得到一个片段。像 `(?<=今天 )` 这样的后行断言永远不可能命中，`^`/`$` 也只会锚在片段的两端，而不是整段文本的两端。这两种情况都会悄悄失效，不如干脆不支持。

函数也不接受：它把一个声明式的选项变成了命令式代码，而且同样只能按片段整体判断。传 `RegExp`、函数、`true`、`{}` 或空数组，都等于没传这个选项；数组里的非字符串项会被丢弃。

## 刻意不做的两个写法

`onSkip` 回调和成对的 `{{ }}` 标记是刻意不做的。它们会在 `skip` 列表已经够用的场景里，再引入一个回调和一层解析；而调用方手上就有文本，可以自己算出这个列表，例如 `[...text.matchAll(/[A-Z]{1,2}[1-5]/g)].map((m) => m[0])`。
