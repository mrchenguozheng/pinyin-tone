# `skip`

`M2`、`A4`、`O2` 会被当成拼音——`m`、`a`、`o` 本身就是音节，所以 `M2` 出来是 `Ḿ`。`skip` 让你在选项里一次说清哪些片段要保持原样。

English: [skip.md](skip.md)

```javascript
markTones('M2 货币供应量 hao3', {skip: 'M2'});   // 'M2 货币供应量 hǎo'
markTones('M2 A4 N3', {skip: ['M2', 'A4']});     // 'M2 A4 Ň'
```

## 规则

参数可以是字符串也可以是数组，比的是**整个片段**，而且区分大小写：`'M2'` 碰不到 `M20`（那是另一个片段），也碰不到 `m2`（那是另一个字符串）。规则就这一条：没有模式匹配，没有回调判断，文本里也不需要任何标记字符。

## 一条规则管住这个片段的每一次出现

`M2 M2` 得到 `M2 M2`，不会「留一个、转另一个」。一次调用里既要转又要留，就把文本切开，分别调。

```javascript
markTones('M2 M2', {skip: 'M2'});  // 'M2 M2'
```

只有本来就会被转换的片段才会去查规则——这是省时间的做法，不算第二条规则。

## 文本里没有标记字符

因为文本里不带标记，普通内容可以原样通过：

```javascript
markTones('C:\\Users');        // 原样    一个路径
markTones('\\texttt{ni3}');    // '\\texttt{nǐ}'  一条 LaTeX 命令
markTones('\\ni3');            // '\\nǐ'  反斜杠只是普通字符
```

最后一条单说：反斜杠不起保护作用。只要看着像音节，前面加什么都会照常标调。要它保持原样，就写进 `skip`——这是「别动它」的唯一途径，输入本身因此不带任何指令。

## 为什么不收 `RegExp`

正则是故意不收的：正则的意思是「在文本里找」，而这里的规则只看得到一个片段。`(?<=今天 )` 这种后行断言永远不可能命中，`^`/`$` 也只锚在片段两端，不是整段文本的两端。两种情况都是悄悄失效，不如干脆不支持。

函数也不收：它把声明式的选项变成了命令式代码，而且一样只能按片段整体判断。传 `RegExp`、函数、`true`、`{}` 或空数组，都等于没传这个选项；数组里的非字符串项会被丢掉。

## 刻意没做的两种写法

`onSkip` 回调和成对的 `{{ }}` 标记，都是刻意没做的。`skip` 列表已经够用，再加它们会多出一个回调和一层解析；而调用方手上就有文本，这个列表自己算得出来，比如 `[...text.matchAll(/[A-Z]{1,2}[1-5]/g)].map((m) => m[0])`。
