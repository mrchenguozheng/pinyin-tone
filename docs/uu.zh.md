# `ü`、冒号、`ê`，以及没有元音的叹词

这一页讲三件事：一个字母的两种 ASCII 写法，用 `^` 表示的韵母，以及一个元音都没有的音节。

English: [uu.md](uu.md)

## `ü` 的两种拼写

`j`/`q`/`x`/`y` 后面，规范写法（`ju`、`jue`、`juan`、`jun`）和字面写法（`jv`、`jve`、`jvan`、`jvn`）都能输入，输出一律是规范写法——《汉语拼音方案》要求这几个声母后面省掉两点：

```javascript
markTones('jv1'); // 'jū'  字面写法输入，规范写法输出
markTones('ju1'); // 'jū'  规范写法输入，规范写法输出
```

`n` 和 `l` 不参与这层转换：这两个声母后面，`u` 和 `ü` 是两个不同的音，所以 `nv3` 是 `nǚ`，`nu3` 是 `nǔ`。`nu:3` 也得到 `nǚ`，但那是你明确要两点，不是自动转的。

## 冒号要的就是那两点

冒号代表 `ü` 上面那两点。它只有两个位置算数：紧跟在它所依附的 `u`/`v` 后面，或者放在整个音节末尾。冒号后面的字母仍属于同一个韵母，所以 `lu:e4` 是 `lüè`，不是 `lü` 再加 `é`；`jv:an1` 和 `jvan:1` 都得到 `jüān`。写到别处（`j:van1`、`jva:n1`）就是把标记放错了地方，整个音节原样返回。

声母不检查合法与否：`gu:1` 得到 `gǖ`，`u:e1` 得到 `üē`。两个都不是合法音节，但都是故意这么设计的：

```javascript
markTones('ju1 ju:1'); // 'jū jǖ'  两种写法可以写在同一行
markTones('juan:1');   // 'jüān'
markTones('lu:e4');    // 'lüè'
markTones('gu:1');     // 'gǖ'
markTones('u:e1');     // 'üē'
```

没有把整段文本切成字面写法的开关，也没有一次返回两种写法的函数。要哪种就在音节上写出来，想并排看就调两次。

### 冒号什么时候落空

三种情况会原样返回：没有 `u`/`v` 能让两点落上去；冒号落在的 `u` 会被词表读成辅音 `v`，等于凭空多出一个你没写过的字母；或者冒号不在那两个位置上。

```javascript
markTones('ma:1');    // 'ma:1'    没有 u/v 能落两点
markTones('ji:1');    // 'ji:1'    同上
markTones('uang:1');  // 'uang:1'  u 会变成辅音 v
markTones('shui:3');  // 'shui:3'  同上
markTones('j:van1');  // 'j:van1'  位置不对
markTones('jva:n1');  // 'jva:n1'  位置不对
```

### 冒号落在 `v` 上不算请求

`v` 本身就是 `ü` 的 ASCII 写法，所以 `jv:1` 和 `ju:1` 没区别。要是开头那个 `v` 在词表里是辅音，冒号就什么都不加，`vv:1` 等于 `vv1`——两者都是 `vǖ`，因为词表里那个值写作 `vü`。

```javascript
markTones('jv:1'); // 'jǖ'  跟 ju:1 一样
markTones('vv:1'); // 'vǖ'  跟 vv1 一样
```

## `ê`

`ê` 是个独立韵母，写作 `e^`——caret 就是这个字母头上的扬抑符，套路和冒号一样。它只对 `e` 有效，别的字母不行；而且它跟冒号互斥，因为 `ê` 里没有 `u` 能落两点：

```javascript
markTones('e^');    // 'ê'
markTones('e^2');   // 'ế'
markTones('e^4');   // 'ề'
markTones('be^2');  // 'be^2'  ê 不是 b 的韵母
markTones('e^r');   // 'e^r'   caret 也代替不了 r
```

## 没有元音的音节

`m`、`n`、`ng`、`hm`、`hng` 也在词表里。这类音节没有元音，调号打在**最后一个鼻音**上：`m2` 是 `ḿ`，`ng4` 是 `ǹg`，`hng1` 是 `hn̄g`。

```javascript
markTones('m2');    // 'ḿ'
markTones('ng4');   // 'ǹg'
markTones('hng1');  // 'hn̄g'
```

这二十种可能的形式里有九种是词表条目，照词表里的样子拼写。其余几种（`m3`、`n1`、`ng1`，以及 `hm`/`hng` 的四个声调）由同一条规则推出来，输出时不做区分。

## 预组合字符与组合符

六个字形没有预组合字符，得用「字母 + 组合符」两个码位拼出来；其余字形都是单个码位。渲染出来一样，但按字节或按长度比字符串时不一样。

| 字形 | 码位 |
| --- | --- |
| `ê̄`（ê，一声） | `U+00EA U+0304` |
| `ê̌`（ê，三声） | `U+00EA U+030C` |
| `m̄`（m，一声） | `U+006D U+0304` |
| `m̌`（m，三声） | `U+006D U+030C` |
| `m̀`（m，四声） | `U+006D U+0300` |
| `n̄`（n，一声） | `U+006E U+0304` |

表里剩下的三十个带调字形都是单个码位。
