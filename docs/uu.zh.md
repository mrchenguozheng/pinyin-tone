# `ü`、冒号、`ê`，以及没有元音的叹词

一个字母的两种 ASCII 写法、用 `^` 表示的韵母，以及完全没有元音的音节。

English: [uu.md](uu.md)

## `ü` 的两种拼写

`j`/`q`/`x`/`y` 后面，规范写法（`ju`、`jue`、`juan`、`jun`）和字面写法（`jv`、`jve`、`jvan`、`jvn`）都可以作为输入，输出一律是规范写法——《汉语拼音方案》要求这些声母后省略两点：

```javascript
markTones('jv1'); // 'jū'  字面写法输入，规范写法输出
markTones('ju1'); // 'jū'  规范写法输入，规范写法输出
```

`n` 和 `l` 不参与这层转换：这两个声母后面 `u` 与 `ü` 是两个不同的音，所以 `nv3` 是 `nǚ`，`nu3` 是 `nǔ`。`nu:3` 同样得到 `nǚ`，但那是明确要求两点，不是自动转换。

## 冒号要的是那两点

冒号代表的就是 `ü` 上面那两点。它只有两个合法位置：紧跟在它所依附的 `u`/`v` 之后，或者在整个音节末尾。冒号后面的字母仍属于同一个韵母，所以 `lu:e4` 是 `lüè`，不是 `lü` 再加 `é`；`jv:an1` 和 `jvan:1` 都得到 `jüān`。写在别的位置（`j:van1`、`jva:n1`）就是放错了标记，整个音节原样返回。

声母不参与合法性检查：`gu:1` 得到 `gǖ`，`u:e1` 得到 `üē`。两个都不是合法音节，但都是有意的输出：

```javascript
markTones('ju1 ju:1'); // 'jū jǖ'  两种写法出现在同一行
markTones('juan:1');   // 'jüān'
markTones('lu:e4');    // 'lüè'
markTones('gu:1');     // 'gǖ'
markTones('u:e1');     // 'üē'
```

没有把整段文本切成字面写法的开关，也没有一次返回两种写法的入口：要哪种就按音节请求，需要并排显示就调用两次。

### 冒号什么时候落空

有三种情况会原样返回：没有 `u`/`v` 可以承载两点；冒号落在的 `u` 会被词表读成辅音 `v`，等于多出一个你没写过的字母；或者冒号不在两个合法位置上。

```javascript
markTones('ma:1');    // 'ma:1'    没有 u/v 可以承载两点
markTones('ji:1');    // 'ji:1'    同上
markTones('uang:1');  // 'uang:1'  u 会变成辅音 v
markTones('shui:3');  // 'shui:3'  同上
markTones('j:van1');  // 'j:van1'  位置不对
markTones('jva:n1');  // 'jva:n1'  位置不对
```

### 冒号落在 `v` 上不算请求

`v` 本身就是 `ü` 的 ASCII 写法，所以 `jv:1` 和 `ju:1` 完全一样。当开头的 `v` 在词表里是辅音时，冒号什么都不加，`vv:1` 就等于 `vv1`——两者都是 `vǖ`，因为词表里那个值写作 `vü`。

```javascript
markTones('jv:1'); // 'jǖ'  与 ju:1 相同
markTones('vv:1'); // 'vǖ'  与 vv1 相同
```

## `ê`

`ê` 是一个独立韵母，写作 `e^`——caret 就是这个字母上面的扬抑符，思路和冒号一样。它只属于 `e`，不适用于别的字母；而且它与冒号互斥，因为 `ê` 里没有 `u` 可以承载两点：

```javascript
markTones('e^');    // 'ê'
markTones('e^2');   // 'ế'
markTones('e^4');   // 'ề'
markTones('be^2');  // 'be^2'  ê 不是 b 的韵母
markTones('e^r');   // 'e^r'   caret 也不能代替 r
```

## 没有元音的音节

`m`、`n`、`ng`、`hm`、`hng` 也在词表里。这类音节没有元音，调号标在**最后一个鼻音**上：`m2` 是 `ḿ`，`ng4` 是 `ǹg`，`hng1` 是 `hn̄g`。

```javascript
markTones('m2');    // 'ḿ'
markTones('ng4');   // 'ǹg'
markTones('hng1');  // 'hn̄g'
```

这二十种可能形式里有九种是词表条目，按词表里的样子拼写；其余（`m3`、`n1`、`ng1`，以及 `hm`/`hng` 的四个声调）由同一条规则推出来，输出时不做区分。

## 预组合字符与组合符

有六个字形没有预组合字符，由「字母 + 组合符」两个码位组成；其余字形都是单一码位。两者渲染出来一样，但按字节或按长度比较字符串时并不相同。

| 字形 | 码位 |
| --- | --- |
| `ê̄`（ê，一声） | `U+00EA U+0304` |
| `ê̌`（ê，三声） | `U+00EA U+030C` |
| `m̄`（m，一声） | `U+006D U+0304` |
| `m̌`（m，三声） | `U+006D U+030C` |
| `m̀`（m，四声） | `U+006D U+0300` |
| `n̄`（n，一声） | `U+006E U+0304` |

表里其余的三十个带调字形都是单一码位。
