# `ü`、冒号、`ê`，以及没有元音的叹词

一个字母的两种 ASCII 拼写、一个 `^` 表示一个韵母，还有那些完全没有元音的音节。

English: [uu.md](uu.md)

## `ü` 的两种拼写

`j`/`q`/`x`/`y` 之后，规范拼写（`ju`、`jue`、`juan`、`jun`）与字面拼写（`jv`、`jve`、`jvan`、`jvn`）都能作为输入。输出一律是规范形式——《汉语拼音方案》在这些声母后要求省略两点：

```javascript
markTones('jv1'); // 'jū'  字面输入，规范输出
markTones('ju1'); // 'jū'  规范输入，规范输出
```

`n` 和 `l` 不参与这个投影：那里 `u` 与 `ü` 是两个不同的音，所以 `nv3` 是 `nǚ`，`nu3` 是 `nǔ`。`nu:3` 同样得到 `nǚ`，但那是明确请求两点，不是投影。

## 冒号要的是那两点

冒号就是 `ü` 上面那两点本身。它只有两个合法位置：紧跟在它所依附的 `u`/`v` 之后，或者在整个音节的末尾。冒号后面的字母仍属于同一个韵母，所以 `lu:e4` 是 `lüè`，而不是 `lü` + `é`；`jv:an1` 与 `jvan:1` 都得到 `jüān`。写在别的位置（`j:van1`、`jva:n1`）就是错放的标记，整个 token 原样返回。

声母不做检查——`gu:1` 是 `gǖ`，`u:e1` 是 `üē`，两个都不是合法音节，但都是有意渲染的：

```javascript
markTones('ju1 ju:1'); // 'jū jǖ'  两种拼写在同一行
markTones('juan:1');   // 'jüān'
markTones('lu:e4');    // 'lüè'
markTones('gu:1');     // 'gǖ'
markTones('u:e1');     // 'üē'
```

没有把整串切成字面拼写的开关，也没有一次返回两种形式的入口——按 token 请求，需要并排就调两次。

### 冒号什么时候落空

三种情况原样返回：没有 `u`/`v` 可以承载两点；它落在的 `u` 会被词表读成辅音 `v`，等于冒出一个你没写过的字母；或者冒号不在两个合法位置上。

```javascript
markTones('ma:1');    // 'ma:1'    没有 u/v 可以放两点
markTones('ji:1');    // 'ji:1'    同上
markTones('uang:1');  // 'uang:1'  u 会变成辅音 v
markTones('shui:3');  // 'shui:3'  同上
markTones('j:van1');  // 'j:van1'  位置不对
markTones('jva:n1');  // 'jva:n1'  位置不对
```

### 冒号落在 `v` 上不算请求

`v` 本身就是 `ü` 的 ASCII 拼写，所以 `jv:1` 与 `ju:1` 完全一样。当那个打头的 `v` 在词表里是辅音时，冒号什么也不加，`vv:1` 就是 `vv1`——两者都是 `vǖ`，因为词表里那个值是 `vü`。

```javascript
markTones('jv:1'); // 'jǖ'  与 ju:1 相同
markTones('vv:1'); // 'vǖ'  与 vv1 相同
```

## `ê`

`ê` 是一个独立的韵母，写作 `e^`——caret 就是那个扬抑符，和冒号是同一套思路。它只属于 `e`，不适用于别的字母，并且与冒号互斥，因为 `ê` 没有 `u` 可以承载两点：

```javascript
markTones('e^');    // 'ê'
markTones('e^2');   // 'ế'
markTones('e^4');   // 'ề'
markTones('be^2');  // 'be^2'  ê 不是 b 的韵母
markTones('e^r');   // 'e^r'   caret 也不能代替 r
```

## 没有元音的音节

`m`、`n`、`ng`、`hm`、`hng` 也在词表里。没有元音时，调号标在**最后一个鼻音**上：`m2` 是 `ḿ`，`ng4` 是 `ǹg`，`hng1` 是 `hn̄g`。

```javascript
markTones('m2');    // 'ḿ'
markTones('ng4');   // 'ǹg'
markTones('hng1');  // 'hn̄g'
```

二十种可能形式里有九个是词表条目，按列出的样子拼写；其余（`m3`、`n1`、`ng1`、`hm`/`hng` 的四个声调）由同一条规则推出，输出中不做区分。

## 预组合字符与组合符

有六个字形没有预组合字符，由「字母 + 组合符」组成；其余是单一码位。两者渲染出来一样，但按字节或按长度比较字符串时是不同的。

| 字形 | 码位 |
| --- | --- |
| `ê̄`（ê，一声） | `U+00EA U+0304` |
| `ê̌`（ê，三声） | `U+00EA U+030C` |
| `m̄`（m，一声） | `U+006D U+0304` |
| `m̌`（m，三声） | `U+006D U+030C` |
| `m̀`（m，四声） | `U+006D U+0300` |
| `n̄`（n，一声） | `U+006E U+0304` |

表里其余三十个带调字形都是单一码位。
